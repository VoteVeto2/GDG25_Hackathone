# GDG 2025 Hackathon Web App

A modern web application built for the GDG 2025 Hackathon using React and Vite.

## Features

- ⚡ **Fast Development** - Powered by Vite for lightning-fast HMR (Hot Module Replacement)
- ⚛️ **React 18** - Modern React with latest features
- 🎨 **Responsive Design** - Works great on desktop and mobile devices
- 🚀 **Ready to Customize** - Easy to extend with your own components and features

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/VoteVeto2/GDG25_Hackathone.git
cd GDG25_Hackathone
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the app for production
- `npm run preview` - Preview the production build locally

## Customization

To customize this app for your hackathon project:

1. Edit `src/App.jsx` to add your own components and logic
2. Modify `src/App.css` and `src/index.css` for custom styling
3. Add new components in the `src/` directory
4. Update the title and metadata in `index.html`
